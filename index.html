What Is a Sqid?

A Sqid (pronounced "squid") is a short ID generated from a number by the open-source Sqids library. Instead of showing a raw database ID such as /orders/127, you can show /orders/EwF: shorter, easier to read, and it doesn't reveal how many records you have at a glance.

Sqids are made only of letters and digits, so they are safe in URLs. The same number always gives the same Sqid, and a built-in blocklist keeps common profanity out of generated IDs.

How to Use This Tool

  1. Pick a direction. Choose Encode to turn numbers into Sqids, or Decode to turn Sqids back into numbers.
  2. Enter your input. Type a number or paste a Sqid. Separate numbers with commas to pack them into a single Sqid, and put each item on its own line to convert a whole list. Press Random to try a unique 64-bit ID.
  3. Read the result. It updates as you type.
  4. Copy or swap. Copy the result, or use the swap button to feed it back in and check the round trip.

When to Use Sqids

  • Public URLs Replace numeric IDs in links, such as /user/EwF instead of /user/127.
  • Short references Order numbers, invite codes, ticket IDs, and short links that people may read aloud or type.
  • Hiding sequence at a glance Consecutive IDs don't look consecutive.

Don't use Sqids for security. Anyone who knows the alphabet can decode them, so they are not a replacement for encryption, access control, or secret tokens.

Frequently Asked Questions

What numbers can I encode?

Any whole number from 0 up to 18,446,744,073,709,551,615 (the largest unsigned 64-bit integer). Negative numbers and decimals are not supported. Separate numbers with commas to pack them into one Sqid (1, 2, 3 becomes 86Rf07), and put items on separate lines to convert many at once.

Are Sqids secure or encrypted?

No. Sqids is an encoding, not encryption. Anyone who knows the alphabet can decode a Sqid back to its number, so never use Sqids for passwords, tokens, or anything that must stay secret.

Will I get the same Sqid every time?

Yes. Encoding is deterministic: the same number always produces the same Sqid with the same settings. This tool uses the default Sqids alphabet and no minimum length, so its results match any official Sqids library running with default settings.

Can I use a custom alphabet or a minimum length?

The Sqids libraries let you shuffle your own alphabet and pad IDs to a minimum length, which changes the output. This tool uses the defaults; configure the options in your own code if you need them.

What happens if one Sqid contains several numbers?

Sqids can pack multiple numbers into a single ID. If you decode one, all of its numbers are shown. For example, 86Rf07 decodes to 1, 2, 3.

Is Sqids the same as Hashids?

Sqids is the successor to Hashids, from the same authors. The algorithm is different, so a Hashids ID cannot be decoded as a Sqid and vice versa.

How are Sqids different from UUIDs?

A UUID is a 36-character random identifier generated without a database. A Sqid is a short encoding of a number you already have, such as an auto-increment ID, and can be decoded back to it.

Is my data sent anywhere?

No. Encoding and decoding run entirely in your browser with WebAssembly. Nothing you type is uploaded to a server.
